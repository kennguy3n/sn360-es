SN360-ES — Gmail & Outlook banner / label mockup

Visual reference for stakeholders. Banner CSS, HTML template, copy, icons, chip classes, and tier palettes are taken verbatim from the sn360-es codebase (internal/service/action/banner_renderer.go, internal/translation/banners/en.json, internal/constant/{tiers,categories}.go, pkg/email_provider/gmail/label_provider.go).
How to read this mockup. Gmail renders SN360 labels as coloured chips next to the subject; Outlook renders them as coloured category dots/pills at the right of each row. SN360-ES creates these natively via the Gmail Labels API and the Outlook Master Categories API — no custom inbox UI is required. The reading-pane view below shows the HTML banner that gets injected into the message body at delivery time.
