# Loadtest corpus

This directory holds bulk fixtures used by load and stress benchmarks
against the SN360-ES pipeline. Files here are **not** required for
unit tests or CI; regular evaluation work uses
[`../evaluation/`](../evaluation/) instead.

## Producing a loadtest corpus

Loadtest fixtures are generated by the same tool as the evaluation
corpus, just with a larger per-category count and a dedicated output
directory:

```bash
go run ./scripts/corpus_generator/ \
    --output-dir ./scripts/corpus/loadtest/ \
    --count-per-category 2000 \
    --seed 42
```

This produces ~32,000 emails (one per-category JSON file plus a
combined `all.json`). The files mirror the schema in
[`../../corpus_schema.json`](../../corpus_schema.json) so the same
validator and model-validation tooling works against them.

## Git hygiene

Generated `*.json` files in this directory are gitignored — only this
README and any handwritten driver scripts should ever be committed.
Regenerate locally whenever you need a fresh dataset.
